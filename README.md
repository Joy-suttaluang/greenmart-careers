# เว็บไซต์สมัครงาน กรีนมาร์ท (เดโม)

ไฟล์: `greenmart-careers.html` — เปิดได้โดยตรงในเบราว์เซอร์ ไม่ต้องติดตั้งอะไรเพิ่ม

## ฟีเจอร์หลัก

### หน้าเว็บสาธารณะ
- **หาสาขาใกล้บ้าน** — เลือกจังหวัดในหน้าแรก ระบบแสดงสาขาที่ตรงกันทันที
- **ตำแหน่งงาน** — 5 ตำแหน่ง พร้อมเงินเดือน หน้าที่ความรับผิดชอบ และคุณสมบัติ
- **สวัสดิการ** — สรุป 8 รายการ
- **รายชื่อสาขา** — 12 สาขาทั่วประเทศ กรองตามจังหวัดได้
- **ใบสมัครงาน** — ฟอร์มกรอกข้อมูลผู้สมัคร (ชื่อ, เบอร์โทร, อีเมล, ตำแหน่ง, สาขา, ประสบการณ์, หมายเหตุ)
- **แชทบอท AI "น้องใบเขียว"** — ตอบคำถามเรื่องเงินเดือน สวัสดิการ หน้าที่งาน และสาขา โดยใช้ข้อมูลที่ฝังไว้ในเว็บเท่านั้น (เชื่อมต่อ Claude API โดยตรงจากเบราว์เซอร์)

### แดชบอร์ดแอดมิน
- เข้าถึงผ่านปุ่ม "แอดมิน" บนเมนู หรือมุมล่างของหน้าเว็บ
- รหัสผ่านเดโม: **`admin123`**
- ดูใบสมัครทั้งหมด, สถิติสรุป (จำนวนใบสมัคร / สาขาที่มีผู้สมัคร / ใบสมัครสัปดาห์นี้)
- กรองตามตำแหน่งงาน, ลบรายการ
- **ดาวน์โหลดใบสมัครเป็นไฟล์ CSV** เปิดใน Excel ได้ทันที ภาษาไทยไม่เพี้ยน

## วิธีแก้ไขข้อมูล

ข้อมูลทั้งหมดอยู่ในไฟล์เดียว แก้ได้ตรง ๆ ในส่วน `<script>` ของ `greenmart-careers.html`:

| ต้องการแก้ | ตัวแปร |
|---|---|
| ชื่อบริษัท | `COMPANY_NAME` |
| ตำแหน่งงาน / เงินเดือน / หน้าที่ | `POSITIONS` |
| สวัสดิการ | `BENEFITS` |
| รายชื่อสาขา | `BRANCHES` |
| รหัสผ่านแอดมิน | `ADMIN_PASSWORD` |
| สีธีม (แบรนด์) | ตัวแปร CSS ใน `:root` เช่น `--green`, `--marigold`, `--bg` |

## ข้อจำกัดของเดโมนี้ (สำคัญ)

- **ข้อมูลใบสมัครเป็นแบบ shared storage** — ทุกคนที่เปิดไฟล์นี้จะเห็นใบสมัครชุดเดียวกัน เหมาะสำหรับทดสอบ/นำเสนอ ไม่ใช่สำหรับเก็บข้อมูลจริงของผู้สมัคร
- **รหัสผ่านแอดมินเป็นแบบฝั่ง client** ไม่มีการเข้ารหัสหรือระบบยืนยันตัวตนจริง ใครก็สามารถดูโค้ดแล้วเห็นรหัสผ่านได้
- หากต้องการใช้งานจริงในองค์กร ควรมี **ฐานข้อมูลจริง + ระบบล็อกอินแอดมินที่ปลอดภัย + เซิร์ฟเวอร์ฝั่งหลังบ้าน (backend)** แทนการเก็บข้อมูลไว้ในเบราว์เซอร์

## หมายเหตุเรื่องแบรนด์

เว็บไซต์นี้ใช้ชื่อและโลโก้สมมติ "กรีนมาร์ท" ที่สร้างขึ้นเองทั้งหมด ไม่ได้ใช้โลโก้หรือเครื่องหมายการค้าของบริษัทจริงใด ๆ หากต้องการปรับให้ตรงกับแบรนด์จริงที่คุณมีสิทธิ์ใช้งาน สามารถแก้ไขสี ชื่อ และโลโก้ในไฟล์ได้ตามต้องการ
